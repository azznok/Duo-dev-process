# Gallery of the owner's verdicts

> WRITTEN BY: the supervisor only, with the owner's words. BUDGET: none (one line per verdict; read in part by the art judge).
The owner's verdicts on images (captures, sheets, concepts). The skill `art-judge` reads the entries that
resemble the image being judged: the owner's reasons weigh more than the canon. A disagreement of the
owner with the judge enters here with its reason and recalibrates the canon (skill `art-judge` § Calibration).

Verdicts live in `docs/art/gallery/verdicts.md`, one line each:

`YYYY-MM-DD | <image path> | VALID | REFUSED | "<the owner's words>" | <source: playtest, question, session>`

- An empty reason (`""`) means the reason was not written: the source says where to look; never invent it.
- A judge verdict confirmed by the owner enters as is, with source `judge confirmed`.
- Images are kept (LFS) next to the verdict file or in `docs/art/refs/`; a verdict on a deleted image is moved
  to `docs/journal/`, never dropped.
