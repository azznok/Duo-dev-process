# Journal

> WRITTEN BY: everyone (append only). BUDGET: none (never loaded by default).
The detailed story (what was tried, dropped, and why) lives here, not in `docs/STATE.md`. One file per
day: `YYYY-MM-DD.md` (supervisor notes: `YYYY-MM-DD-supervisor.md`).

- **Dated entries**: `## HH:MM — <who> — <subject>` then the text. Never edit a past entry; correct it by a new one.
- **Verbatim archives**: when a loaded document goes over its budget, the old text moves here WORD FOR
  WORD under `## Archive <DOC> <task nnn>`, and the document keeps one pointer line. Knowledge is never
  deleted, only archived.
- **Process reviews** add a dated section `## Process review <nnn>` (outputs, tables, proposals).
