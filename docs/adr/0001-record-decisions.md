## ADR-0001 — Record decisions as one file per ADR — *Decided by the template* (TASK 000)

**Context**: an autonomous duo (and several duos in parallel) takes decisions every day; the owner takes
others through the supervisor. A single decisions file grew to thousands of lines, was loaded whole,
and two duos editing it at the same time produced merge conflicts on every merge.

**Decision**:
- a) One decision = one file `docs/adr/NNNN-<slug>.md`, header
  `## ADR-NNNN — <title> — *<status>* (TASK <nnn>)`, sections Context / Decision / Consequences.
- b) Numbers come from a shared counter (`bin/harness/next-adr.ps1`), never chosen by hand.
- c) `docs/DECISIONS.md` is an index generated by `tools/doc/adr.py index` after each merge; nobody edits it.
- d) An ADR is never rewritten: a new ADR supersedes it, the old one's status says so.

**Consequences**: reading one decision costs one small file; two duos never touch the same decision
file; the index can be checked (`adr.py index --check`). Abandoned: free-form decision notes inside
other docs (they point to an ADR instead).
